# Misi Pendapat Hebat! — Bahasa Melayu Tahun 4

Permainan pembelajaran interaktif untuk tajuk **Memberi Pendapat (Bahagian C)**. Dibina menggunakan HTML, CSS dan JavaScript tanpa pemasangan atau pustaka luar.

## Kandungan
- `index.html` — nota infografik, pautan video YouTube, kuiz 8 soalan, markah bintang, maklum balas, kesan bunyi dan suara peranti (jika tersedia), cabaran menulis.
- Reka bentuk responsif untuk telefon, tablet dan komputer.
- Nama murid hanya digunakan pada paparan setempat; tiada data dihantar atau disimpan.

## Cara guna
1. Muat turun dan ekstrak fail ZIP.
2. Buka `index.html` menggunakan pelayar moden (Chrome, Edge, Safari atau Firefox).
3. Tekan butang **Bunyi: ON**. Suara Bahasa Melayu bergantung pada suara yang tersedia dalam peranti/pelayar.
4. Untuk paparan terbaik di kelas, gunakan skrin penuh.

## Terbitkan secara percuma di GitHub Pages
1. Log masuk ke GitHub dan cipta repositori baharu, contohnya `misi-pendapat-hebat`.
2. Muat naik `index.html` ke akar repositori (dan fail README ini jika mahu).
3. Buka **Settings → Pages**.
4. Di bahagian **Build and deployment**, pilih **Deploy from a branch**, pilih `main` dan folder `/(root)`, kemudian tekan **Save**.
5. Tunggu proses selesai. GitHub akan memaparkan URL laman. Kongsi URL tersebut dengan murid.

> Saya tidak boleh mencipta repositori GitHub atau URL awam tanpa akses ke akaun anda. Fail ini sudah disediakan untuk dimuat naik terus ke GitHub Pages.

## Rujukan dan nota kurikulum
- DSKP Bahasa Melayu Tahun 4 (SK), KSSR Semakan 2017: rujukan umum boleh dicapai melalui portal panitia Bahasa Melayu KPM/sekolah: https://sites.google.com/moe-dl.edu.my/skblm-kurikulum/home/dokumen-standard-kurikulum-pentaksiran-dskp
- Standard berkaitan dalam DSKP BM Tahun 4 (SK): **SK 1.2 / SP 1.2.1** (bertutur untuk menilai dan memberikan alasan tentang sesuatu perkara secara bertatasusila); **SK 3.2 / SP 3.2.1** (membina dan menulis ayat serta perenggan daripada bahan multimedia); dan **SP 3.2.2** (menghasilkan jawapan pemahaman berdasarkan soalan bertumpu dan bercapah secara kritis dan kreatif). Rujukan standard penulisan disemak melalui salinan DSKP BM Tahun 4. Sila selaraskan aktiviti aplikasi Bahagian C ini dengan kehendak soalan dan RPT sekolah. Permintaan asal menyebut “DSKP PK Tahun 3”, sedangkan tajuk ialah Bahasa Melayu Tahun 4 arus perdana; bahan ini menggunakan DSKP BM Tahun 4 (SK) sebagai rujukan asas, bukan DSKP Pendidikan Khas Tahun 3.
